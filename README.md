## How I Approach a Project

Roughly the same process every time, whether the dataset is messy vendor invoices or a customer transactions log:

1. Understand the business question first
2. Pin down what "done" looks like
3. Collect and clean the data
4. Explore it before jumping to conclusions
5. Run the actual analysis
6. Visualize what matters
7. Build a dashboard if the audience needs to explore it themselves
8. Write up the insight and what to do about it
